# 📚 Документация ShadowGram

**ShadowGram** — профессиональная модульная экосистема для автоматизации, управления фермами аккаунтов Telegram, изолированного запуска клиентских процессов и визуального проектирования сценариев выполнения.

## ⚡ Ключевые возможности

1. **Многопрофильная ферма аккаунтов:**
   - Поддержка независимых ферм с собственными списками аккаунтов, прокси и настройками (`active_farm.txt`, `config.json`).
   - Синхронизация сессий между форматами `Telethon`/`Pyrogram`/`Hydrogram` (`.session`) и нативным Telegram Desktop (`tdata`).

2. **Аппаратная и системная маскировка (Stealth Mode):**
   - Изоляция процессов через `bubblewrap` (bwrap) и `firejail`.
   - Подмена DMI-данных (`sys_vendor`, `product_name`) через виртуальные пайпы `/sys/devices/virtual/dmi/id/`.
   - Корректная подмена локали и часового пояса `/etc/localtime` для каждого запущенного аккаунта.

3. **Сетевая инфраструктура:**
   - Локальный прокси-маршрутизатор на базе `gost` (v3).
   - Интеграция с `proxychains4` для принудительного направления трафика через SOCKS5/HTTP пулы.

4. **Визуальный сценарист (Node Editor):**
   - Графическое построение логики из нод: работа с ботами, каналами, паузы, ротация строк из файлов, парсинг сообщений, проверки подписок.
   - Сохранение и перенос графов в формате `.sgn`.

## 🛠️ Стек технологий

- **Язык:** Python 3.10+
- **GUI:** PyQt6 / Qt Designer
- **Telegram MTProto Client:** Hydrogram (форк Pyrogram с поддержкой актуальных слоев MTProto)
- **Изоляция:** bubblewrap, firejail
- **Сетевой слой:** gost v3, proxychains4, aiohttp
- **Хранилище данных:** JSON (`config.json`), SQLite (`config.db`), INI/Conf (`proxychains.conf`)
