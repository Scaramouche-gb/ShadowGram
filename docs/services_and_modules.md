# ⚙️ Сервисы и модули (Services & Modules)

ShadowGram предоставляет модульный фреймворк для написания сценариев и пакетных сервисов автоматизации на базе класса `BaseModule`.

---

## 1. Базовый модуль автоматизации (`BaseModule`)

Все модули и сценарии наследуются от `src/core/base_module.py`:

```python
from src.core.base_module import BaseModule

class CustomModule(BaseModule):
    MODULE_NAME = "Мой модуль"
    MODULE_DESC = "Описание выполняемых действий"
    
    # Задержка шахматного запуска между аккаунтами (мин, макс сек)
    START_DELAY = (5, 20)
    
    # Флаг циклического (бесконечного) выполнения
    IS_CYCLIC = False
    CYCLE_DELAY = (3600, 7200)

    async def run(self, **kwargs):
        # 1. Инициализация сессии и прокси
        if not await self.init_client():
            return False

        # 2. Выполнение логики через self.client (Hydrogram Client)
        me = await self.client.get_me()
        self.log(f"Авторизован как {me.first_name}", "success")
        
        # Безопасная пауза с поддержкой отмены и паузы из UI
        await self.sleep(5)
        
        # 3. Завершение работы
        await self.cleanup()
        return True
```

### Ключевые возможности `BaseModule`:
- **`init_client()`** — автоматически поднимает нужный тип туннеля (gost или прямой SOCKS5), находит сессионный файл `.session` и соединяется с дата-центром Telegram.
- **`log(msg, status)`** — потокобезопасная отправка цветного статуса в консоль UI и синхронная фиксация в аналитике.
- **`wait_global_delay()`** — глобальный кросс-аккаунтный замок (`_global_action_lock`), гарантирующий интервал между опасными действиями (например, подписками) от разных аккаунтов.
- **`sleep(seconds)`** — пауза, реагирующая на остановку пользователем (`is_stopped`) и кнопку паузы (`is_paused`), с коэффициентом замедления в режиме `stealth_mode`.

## 2. Встроенные сервисы (`src/services/`)

### Массовый конвертер и упаковщик сессий (`mass_session_service.py`)
- Пакетная конвертация между форматами сессий:
  - Telethon ↔ Pyrogram / Hydrogram.
  - Извлечение AuthKey и DC ID.
- Автоматическая валидация работоспособности сессий через `get_me()`.
- Выгрузка готовых архивов с разделением на валид / невалид / спамблок.

### Подготовка агрегаторов (`agregator_prep_service.py`)
- Предварительная настройка аккаунтов для просмотра и реакции в каналах-агрегаторах.
- Автоматический прогрев и распределение по тематическим папкам.

---

## 3. Логирование и аналитика (`src/core/logger.py`)

- **Системный лог:** Все ключевые события приложения записываются в файл `shadowgram.log` с ротацией.
- **Логи аккаунтов:** Индивидуальные логи хранятся непосредственно в папках аккаунтов (`farms/<farm>/accounts/<acc>/log.txt`).
- **База данных действий (`config.db`):** SQLite база с историей подписок, кликов, отправленных сообщений и ошибок аккаунтов.
